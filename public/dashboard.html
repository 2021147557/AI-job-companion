선택한 공고

아직 선택한 공고가 없습니다. 추천 공고에서 골라보세요 →

시나리오 안내

1. 포트폴리오 → 공고 추천

희망 직무, 기술 스택, 프로젝트를 입력하면 워크넷/고용24 공고와 매칭하여 추천합니다.

2. 모의 면접

선택한 공고에 맞춘 6개 면접 질문이 생성되고, 답변에 대한 피드백을 받습니다.

3. 면접 당일 체크리스트

면접 일정을 입력하면 시간/위치를 기반으로 체크리스트가 자동 생성됩니다.

4. 면접장 주변 지도

Kakao Local API 로 면접장 주변 카페, 편의점, 프린트 가게, 정장 대여소, 지하철역을 보여드립니다.
