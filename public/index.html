AI 취업 동행 서비스

서비스 소개 2026 IP 팀 프로젝트

쉬었음 청년의 취업 준비 과정에서 발생하는 정보 탐색, 면접 준비, 면접 당일 실행의 막막함을 해결하는 LLM · 지도 API 기반 모바일 매시업 서비스입니다.

서비스 흐름

  1. 포트폴리오 입력
  2. 워크넷/고용24 + OpenAI 기반 채용 공고 추천
  3. 선택한 공고로 맞춤 모의 면접
  4. 면접 당일 체크리스트 + 면접장 주변 지도

사용 기술

  • Web API (런타임 호출): 워크넷/고용24, Kakao Local, Kakao Maps, OpenAI
  • 그래프 라이브러리: d3.js
  • 모바일 정보: Geolocation API (현재 위치)
  • 서버: Node.js + Express + SQLite
